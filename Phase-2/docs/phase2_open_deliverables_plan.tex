\section{Deliverable 4 (Partial): Golden Micro-kernel Traces Across Simulators}
\subsection*{Current Gap}
Golden trace sets are reproducible via tooling, but repository-pinned bundles are not uniformly maintained for QEMU and gem5.

\subsection*{Key Risks}
\begin{itemize}[leftmargin=*]
  \item Regression detection becomes target-biased (Spike-heavy confidence).
  \item Cross-target semantic drift may go unnoticed until late integration.
\end{itemize}

\subsection*{Closure Work Package}
\begin{itemize}[leftmargin=*]
  \item Define canonical golden bundle roots:
  \begin{itemize}
    \item \codepath{Phase-2/golden_out_spike_matrix/}
    \item \codepath{Phase-2/golden_out_qemu_matrix/}
    \item \codepath{Phase-2/golden_out_gem5_matrix/}
  \end{itemize}
  \item Pin one reduced matrix per target (same workloads, sizes, flag modes).
  \item Commit \codepath{trace_index.csv}, manifest, and invariant summary artifacts for each target.
\end{itemize}

\subsection*{Done-When Gate}
All three targets have pinned golden bundles with matching workload/flag grids and replayable manifests.

\section{Deliverable 5 (Partial/Good): Golden Output Artifacts Reproducibility}
\subsection*{Current Gap}
Deterministic JSON/CSV replay exists, but artifact packaging policy is implicit and Parquet support is not formalized.

\subsection*{Key Risks}
\begin{itemize}[leftmargin=*]
  \item Teams may produce inconsistent artifact layouts across branches.
  \item Long-term compatibility checks are harder without a documented package contract.
\end{itemize}

\subsection*{Closure Work Package}
\begin{itemize}[leftmargin=*]
  \item Standardize required outputs per golden run:
  \begin{itemize}
    \item \codepath{*_windows.csv}
    \item \codepath{*_summary.json}
    \item \codepath{plots/invariant_report.csv}
    \item \codepath{trace_index.csv}
  \end{itemize}
  \item Add explicit packaging policy (CSV/JSON mandatory; Parquet optional).
  \item Record schema/tool metadata in a top-level run metadata file.
\end{itemize}

\subsection*{Done-When Gate}
Two reruns of the same manifest produce identical required artifacts and pass deterministic SHA checks under CI.

\section{Deliverable 8 (Not Done): Dataset Governance}
\subsection*{Current Gap}
No dedicated governance policy file exists (\codepath{Phase-2/DATASETS.md} missing).

\subsection*{Key Risks}
\begin{itemize}[leftmargin=*]
  \item Dataset updates can be made without ownership, compatibility, or review policy.
  \item Trace/mask changes can silently alter acceptance baselines.
\end{itemize}

\subsection*{Closure Work Package}
\begin{itemize}[leftmargin=*]
  \item Author \codepath{Phase-2/DATASETS.md} with:
  \begin{itemize}
    \item Dataset ownership and review requirements.
    \item Versioning rules for \codepath{datasets/manifest.json} (\texttt{dataset\_version} semantics).
    \item Compatibility matrix (engine schema version, adapter metadata schema).
    \item Immutability rules for pinned golden references.
  \end{itemize}
  \item Enforce manifest diffs in PR templates/checks.
\end{itemize}

\subsection*{Done-When Gate}
Any dataset change requires version bump, owner sign-off, and passing replay/invariant checks.

\section{Deliverable 9 (Not Done): CI Integration for Phase-2}
\subsection*{Current Gap}
No dedicated Phase-2 workflow currently executes cross-target smoke, invariants, and determinism checks in CI.

\subsection*{Key Risks}
\begin{itemize}[leftmargin=*]
  \item Regressions are discovered only in manual testing.
  \item Contract drift can merge without automated gating.
\end{itemize}

\subsection*{Closure Work Package}
\begin{itemize}[leftmargin=*]
  \item Add \codepath{.github/workflows/phase2-ci.yml}.
  \item Gate PRs on fast checks:
  \begin{itemize}
    \item \codepath{python3 Phase-2/tests/check_adapter_fixtures.py}
    \item \codepath{python3 Phase-2/tests/check_determinism.py --targets qemu --workload hello --workload-size test}
    \item \codepath{python3 Phase-2/run_cross_target_suite.py --targets cpu qemu --workloads hello --workload-size test --allow-nonzero-exit}
  \end{itemize}
  \item Add optional self-hosted/nightly lane for Spike and gem5 full replay.
\end{itemize}

\subsection*{Done-When Gate}
PR merge is blocked on Phase-2 CI failures; nightly extended jobs publish artifacts and trend deltas.

\section*{Recommended Execution Order}
\begin{enumerate}[leftmargin=*]
  \item Deliverable 8 (\codepath{DATASETS.md}) to lock governance and version semantics.
  \item Deliverable 9 (Phase-2 CI workflow) to enforce checks continuously.
  \item Deliverable 4 (pin QEMU/gem5 golden bundles) under governance + CI.
  \item Deliverable 5 (artifact packaging policy formalization).
\end{enumerate}
