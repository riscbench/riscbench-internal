\section{Technical Description}
CI integration codifies deterministic replay and contract checks as mandatory automated gates, preventing regressions from merging silently.

\section{Implementation Fulfillment}
Gates are implemented by scripts under \codepath{Phase-2/tests/} and \codepath{Phase-2/run_cross_target_suite.py}; CI wiring consumes these entrypoints.

\section{Design \& Architecture}
\subsection*{Function Attributes}
\begin{itemize}[leftmargin=*]
  \item \texttt{check\_adapter\_fixtures.main()}: Inputs=fixture traces/snapshots; Outputs=parser stability pass/fail; Side effects=verifies parser normalization invariance; Failure modes=fixture mismatch.
  \item \texttt{run\_golden\_suite.main()}: Inputs=manifest + replay args; Outputs=golden outputs + pass/fail; Side effects=core replay gate; Failure modes=replay failure.
  \item \texttt{check\_invariants.main()}: Inputs=windows artifact; Outputs=invariant pass/fail; Side effects=validates simulator-independent constraints; Failure modes=constraint violation.
  \item \texttt{check\_determinism.main()}: Inputs=target runs + rerun outputs; Outputs=determinism pass/fail; Side effects=ensures byte-identical reruns; Failure modes=non-deterministic outputs.
  \item \texttt{run\_cross\_target\_suite.main()}: Inputs=target/workload matrix; Outputs=cross-target smoke result; Side effects=validates integration coverage; Failure modes=missing tools/failed runs.
\end{itemize}
