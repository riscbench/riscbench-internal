\section{Technical Description}
This deliverable defines deterministic replay outputs and their identity checks so reruns over fixed inputs produce byte-identical windows and summaries.

\section{Implementation Fulfillment}
Core execution uses \codepath{Phase-2/tests/run_golden_suite.py}; determinism is checked by \codepath{Phase-2/tests/check_determinism.py}; engine output is generated by \codepath{Phase-2/sit_engine_phase1.py}.

\section{Design \& Architecture}
\subsection*{Function Attributes}
\begin{itemize}[leftmargin=*]
  \item \texttt{run\_golden\_suite.load\_manifest()}: Inputs=manifest path; Outputs=manifest object; Side effects=loads replay input set; Failure modes=missing/invalid manifest.
  \item \texttt{run\_golden\_suite.main()}: Inputs=manifest + output dir; Outputs=golden replay artifacts; Side effects=drives replay end-to-end; Failure modes=invariant/replay failures.
  \item \texttt{check\_determinism.collect\_hashes()}: Inputs=golden output dir; Outputs=artifact hash map; Side effects=collects SHA256 per output artifact; Failure modes=missing output files.
  \item \texttt{check\_determinism.main()}: Inputs=target set + knobs; Outputs=pass/fail report; Side effects=asserts byte equality across reruns; Failure modes=hash mismatches.
\end{itemize}
