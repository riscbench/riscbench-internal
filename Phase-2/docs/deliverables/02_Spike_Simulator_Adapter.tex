\section{Technical Description}
Spike adapter normalizes Spike commit logs into Phase-1 ingest contract intervals (\texttt{start\_us,end\_us,core,state} and residency intervals). It is the reference target adapter used to verify marker-driven residency semantics and SIT behavior on deterministic workloads.

\section{Implementation Fulfillment}
Implemented in \codepath{Phase-2/adapters/spike_adapter.py}. Key implementation points:
\begin{itemize}[leftmargin=*]
  \item event parsing: \texttt{\_iter\_events()},
  \item core timeline and state inference: \texttt{\_collect\_core\_timeline()},
  \item normalized outputs: \texttt{build\_state\_intervals()}, \texttt{build\_residency\_intervals()},
  \item artifact writer: \texttt{export\_baseline\_csvs()}.
\end{itemize}
Execution path is wired through \codepath{Phase-2/riscvbench.py} (\texttt{--target spike}) and validated by \codepath{Phase-2/tests/run_spike_golden_pipeline.py}.

\section{Design \& Architecture}
Adapter design is marker-first:
\begin{itemize}[leftmargin=*]
  \item residency and stall markers are detected from instruction encodings,
  \item fallback residency can use PC threshold when markers are absent,
  \item state intervals are emitted in normalized schema and passed to ingest validators.
\end{itemize}
Dependencies: \codepath{Phase-2/ingest/ingest_api.py}, \codepath{Phase-2/sit_engine_phase1.py}.
