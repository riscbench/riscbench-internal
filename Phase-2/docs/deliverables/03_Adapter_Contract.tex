\section{Technical Description}
Adapter contract defines responsibilities and boundaries between simulator-specific parsing and simulator-agnostic SIT computation. The contract prevents semantic leakage by requiring adapters to emit normalized interval artifacts only.

\section{Design \& Architecture}
\subsection*{Contract Shape}
\begin{itemize}[leftmargin=*]
  \item State intervals: \texttt{start\_us,end\_us,core,state[,work\_done]}
  \item Residency intervals: \texttt{start\_us,end\_us,core[,resident]}
\end{itemize}
Engine-owned logic: windowing, SIT equation, summary/export policy.\\
Adapter-owned logic: source parsing, timeline normalization, state/residency inference, schema validation.

\subsection*{Per-Adapter Design Notes}
\begin{itemize}[leftmargin=*]
  \item Spike: instruction-commit log parsing with marker-first residency/stall detection.
  \item QEMU: dynamic TB execution events (\texttt{Trace ...}) as time base; TB disassembly summarizes state class.
  \item gem5: exec-trace or periodic-stats mode with threshold-driven normalization.
  \item CPU: host-runtime synthetic baseline path for smoke validation.
\end{itemize}
