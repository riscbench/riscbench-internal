\section{Technical Description}
This deliverable proves gem5 adapter conformance to the shared ingest contract and prevents SIM-specific SIT policy leakage.

\section{Implementation Fulfillment}
Contract is defined in \codepath{Phase-2/ADAPTERS.md} and validated by \texttt{validate\_state\_df()} and \texttt{validate\_resid\_df()} before engine ingestion.

\section{Design \& Architecture}
\subsection*{Function Attributes}
\begin{itemize}[leftmargin=*]
  \item \texttt{Gem5PlatformAdapter.\_iter\_events()}: Inputs=gem5 raw records; Outputs=platform events; Side effects=platform parse only; Failure modes=parser drift.
  \item \texttt{Gem5PlatformAdapter.\_collect\_core\_timeline()}: Inputs=events + parse config; Outputs=normalized timeline; Side effects=classification and normalization only; Failure modes=timeline inconsistencies.
  \item \texttt{validate\_state\_df()}: Inputs=state interval DataFrame; Outputs=validated state DataFrame; Side effects=schema/domain enforcement; Failure modes=invalid states/columns.
  \item \texttt{validate\_resid\_df()}: Inputs=residency interval DataFrame; Outputs=validated residency DataFrame; Side effects=residency schema enforcement; Failure modes=invalid intervals.
  \item \texttt{sit\_engine\_phase1.main()}: Inputs=validated contract input; Outputs=windows/summary outputs; Side effects=engine-owned SIT policy only; Failure modes=policy/config failure.
\end{itemize}
